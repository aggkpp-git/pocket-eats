# Pocket Eats · Perth V1.1
Mobile-first Streamlit prototype.

## Run
`pip install -r requirements.txt`
`streamlit run app.py`

## Current features
- Pocket restaurant cards
- Restaurant detail page
- Google Maps navigation
- Menu with Chinese / English toggle
- Tags and search including dish names
- Want to go / Been there / Favourite
- Personal rating and notes
- SQLite persistence

## Next phase
Automatic restaurant lookup and official-menu discovery/extraction, with source and last-checked metadata.
